Live Target Execution — Planned Future Work

Executing red-team test cases directly against live API endpoints is on the roadmap but has not yet been implemented. This page is a placeholder.

In the meantime, use the CLI corpus command to generate and export your targeted test corpus, then import the results into your own pentest harness or proxy tool.

📦

1. Browse the Corpus

Use the Corpus Browser to filter and explore the full red-team test case library by category, severity, OWASP mapping, and target model.

⚙️

2. Generate a Targeted Corpus

Use the Generator or the CLI to create a corpus interpolated for your specific target system, then export it as JSON, CSV, or Markdown. 

python aiml_pentest.py corpus \
  --target "MyModel" \
  --output corpus_output/
🔧

3. Execute in Your Harness

Import the exported corpus into your preferred pentest harness, HTTP proxy (Burp Suite, mitmproxy), or scripted test runner to execute payloads against your target.

Roadmap: The Live Target Connection feature — including direct API endpoint testing via httpx, real-time result streaming, and per-test verdict reporting — is planned for a future release. Watch the repository for updates.
